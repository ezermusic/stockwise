Import & validation

Upload one stock file that holds both the system quantity and the physical quantity for every product. XLSX, XLS and CSV are supported, by drag and drop or the file browser. You can also key counts in on the Manual count page.

Single-file import
01

Stock file

One row per product: code, name, system quantity, physical quantity, unit cost and selling price. Category, unit, expiry date, counted by and notes are optional.

Expected file layout

Column names are detected automatically and can be re-mapped before reading the file. Blank numeric cells are read as 0.

  • qty is the system quantity; count is the physical quantity. Variance = system − physical.
  • Required: product code, system quantity and unit cost. Everything else is optional.
  • One row per SKU. If a SKU repeats, the first row is used and the repeat is flagged.

How the numbers are read

Items are matched by SKU/product code. Blank numeric cells are read as 0, including a blank physical quantity (a counted quantity of 0) unless you choose “not counted” above. Non-numeric text is flagged and set to 0. Manual count entries are added to the physical quantity in the file. The original import is never overwritten by the calculated variance.
